Stability & backward compatibility

Visible commands added and removed per release

Diff of the visible --help command tree between consecutive releases, across all releases (not affected by the selector). Commands are matched by resource + verb (the last two path tokens), so top-level regrouping — e.g. datacenter list → compute datacenter list — is not counted as churn. Caveat: a command hidden for backward compatibility drops out of --help, so it counts as "removed" here unless a visible command keeps the same resource + verb — even though it still works. Removals are the main source of breaking changes.

Reproducible: make rebuilds everything. make full builds all stable tags for the version selector. make users refreshes Snap install base. make sprint diffs HEAD vs ~3 weeks ago. Services count drops at v6.10 by design — products were grouped under compute for discoverability. Example coverage stayed ≈100% (99% of leaf commands ship usage examples).
